# Modelo de servicio propuesto

El desarrollador conserva la propiedad técnica del software y opera infraestructura, actualizaciones, respaldos y mantenimiento. Creer administra sus productos y su actividad comercial; sus datos pertenecen a Creer. Este documento describe el producto previsto, no sustituye un contrato firmado.

- Implementación inicial: configuración, identidad, carga acordada y capacitación.
- Suscripción: uso, hosting, soporte, respaldos y correcciones menores.
- Funcionalidades grandes e integraciones: cotización y alcance separados.
- Cancelación: prever exportación de datos y un plazo de conservación y eliminación acordado.
- Soporte: acordar horarios, canal, tiempos de respuesta y restauración de respaldos antes de operar.

No hay precio, plan contratado, SLA ni cobros activos en Capa 01. No se implementa bloqueo automático por mora. La próxima integración de pagos requerirá definir proveedor, moneda, eventos y reglas de acceso.

Roles previstos: administrador de Creer (operación y equipo), ventas (clientes/cotizaciones), editor de catálogo (productos públicos), propietario proveedor (suscripción y operación técnica). Costos solo para administrador de Creer en la política inicial; ampliar permisos de forma explícita si el negocio lo necesita.
